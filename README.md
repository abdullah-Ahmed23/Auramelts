# Aura Melts

## Project info

Aura Melts is a premium web application focused on personalized wellness and AI-driven experiences.

## Getting Started

Follow these steps to set up the project locally:

```sh
# Step 1: Install the necessary dependencies.
npm i

# Step 2: Start the development server.
npm run dev
```

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Framer Motion
- Lucide React
- TanStack Query
- Recharts
